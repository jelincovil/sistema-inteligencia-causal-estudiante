# Kit de la clase (semana 4)

Este es el esqueleto que se completa en vivo. Cada archivo lleva la marca
del bloque de la clase (p. ej. `[BLOQUE 3, min 35–60]`) y cada función por
escribir un TODO numerado con pista. El andamio (imports, `main`, prints,
firma de funciones) ya está: la clase escribe solo los cuerpos marcados.

La solución de referencia está en `../solucion/` (material del profesor:
no se distribuye). `pregunta.md`, `rutas.py`, `Makefile`, `Dockerfile` y
`requirements.txt` ya vienen completos.

Flujo de la clase (ver `../plan_clase.md`):

    make verificar   # BLOQUE 2: esquema C-01 + hashes + pared
    make estimar     # BLOQUE 3: ATE + IC + diagnósticos + trampa
    make registrar   # BLOQUE 4: tarjeta + v0001 + champion + mutación
    make ventanas    # BLOQUE 5: sana / deriva / positividad
    make humo        # BLOQUE 6: el servicio responde y se abstiene

Al terminar, `make demo` corre todo el flujo completo.

# Proyecto — «Puente» (semana 4)

El proyecto del estudiante: un notebook conductor (`proyecto.ipynb`) sobre los
módulos del prototipo (`datos.py`, `estimacion.py`, `registro.py`, `monitor.py`,
`servicio_core.py`, `servicio.py`, `humo.py`), con 22 TODOs para completar en
clase sobre `real/jobs` y una tarea individual que adapta todo el puente a
`real/ihdp` (lo que se entrega: ver `ENTREGA.md`).

```bash
pip install -r requirements.txt
jupyter lab proyecto.ipynb     # o jupyter notebook
make verificar                 # falla con TODO-1: así se empieza
```

La pregunta causal y el estimando se declaran en `pregunta.md` — se lee antes
de tocar código. Los números esperados de los checkpoints están en el notebook;
los tuyos, en la tabla de la sección 7.

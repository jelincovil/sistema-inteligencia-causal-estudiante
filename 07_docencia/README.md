# Material docente (no forma parte del paquete mínimo del estudiante)

Esta carpeta guarda **prototipos y guías de referencia** para docencia. El repositorio público del estudiante (`main`) está pensado para labs, Serie A y proyecto final; lo que hay aquí puede vivir en ramas de trabajo (por ejemplo `semana4/proyecto`).

| Ruta | Contenido |
|------|-----------|
| `semana_4_proyecto/` | Prototipo «Puente» resuelto (IHDP + jobs), servicio FastAPI, evidencia reproducible |

Para clonar solo el flujo del prototipo:

```bash
cd semana_4_proyecto
pip install -r requirements.txt
SIC_ESCENARIO=real/ihdp make demo
```

Ver el README de cada subcarpeta para comandos y entrega.
